# Remove DWAgent from Windows Search & Start Menu Plan

## 1. Investigation Summary & Exact Targets

`DWAgent` currently appears in Windows Search and the Start Menu (`Get-StartApps` ID `Microsoft.AutoGenerated.{9724A02F-1607-B6AC-06DE-6FFB9CC9DB31}`) via its Start Menu shortcut folder, while the background service (`DWAgent` service, `dwagent.exe`, `dwagsvc.exe` under `C:\Program Files\DWAgent`) stays running.

**Targets to Remove**:
1. Start Menu folder & shortcut:
   - `C:\ProgramData\Microsoft\Windows\Start Menu\Programs\DWAgent`
   - `C:\ProgramData\Microsoft\Windows\Start Menu\Programs\DWAgent\DWAgent.lnk`
2. `HKCU:\SOFTWARE\Microsoft\Windows\CurrentVersion\Explorer\FeatureUsage\AppSwitched` entries (4 DWAgent values referencing `dwagent.exe`).

**Protected Exclusions (Untouched)**:
- `C:\Program Files\DWAgent\`
- `C:\Users\Admin\.dwagent\`
- Windows service `DWAgent` (`Running`, `Automatic`) and active processes `dwagent.exe` (`PID 2472`) / `dwagsvc.exe` (`PID 2320`)
- `HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall\DWAgent` (so DWAgent remains properly installed/uninstallable if ever needed later)

---

## 2. Rule 11 Pre-Modification Backup Plan

Create `C:\AI Logs\<DATE>\<TIMESTAMP>\files\` before modifying anything:
- Copy `C:\ProgramData\Microsoft\Windows\Start Menu\Programs\DWAgent\DWAgent.lnk`
- Export `HKCU\SOFTWARE\Microsoft\Windows\CurrentVersion\Explorer\FeatureUsage\AppSwitched` to `files\reg\hkcu_appswitched.reg`
- Verify backed-up files exist and are > 0 bytes before proceeding.

---

## 3. Execution Steps (After Explicit User Approval)

1. Run Rule 11 pre-modification backups and verify non-zero file sizes.
2. Delete `C:\ProgramData\Microsoft\Windows\Start Menu\Programs\DWAgent` (`Remove-Item -Recurse -Force`).
3. Remove the 4 `dwagent.exe` values from `HKCU:\SOFTWARE\Microsoft\Windows\CurrentVersion\Explorer\FeatureUsage\AppSwitched`.
4. If `SearchHost` or `StartMenuExperienceHost` processes are running, stop them so Windows respawns them cleanly and drops any cached Start/Search entry immediately (without touching `DWAgent` service or `explorer.exe`).
5. Run Rule 3 verification and archive `implementation_plan.md`, `transcript.jsonl`, and `transcript_full_snippet.jsonl` per Rule 11.
