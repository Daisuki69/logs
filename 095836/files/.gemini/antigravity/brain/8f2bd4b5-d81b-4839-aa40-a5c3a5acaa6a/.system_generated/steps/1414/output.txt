The search for "Antigravity IDE move or export conversation .gemini antigravity conversations db brain directory" returned the following summary:
In the **Antigravity IDE** (and the broader Gemini Antigravity agent ecosystem), conversation history, context logs, and metadata are split across two primary layers: **human-readable brain artifacts/transcripts** and **internal SQLite/database indexes**[1][2]. 

Depending on whether you are trying to **move/migrate** your conversations between directories/versions (like upgrading to Antigravity IDE 2.0+) or **export** them into readable files, here is how the directory structure works and how to handle them.

---

### 1. Where Antigravity Stores Conversations & Brain Data
Antigravity stores its operational data in two primary locations on your system (depending on your OS, typically Windows `%USERPROFILE%` / `%APPDATA%`[1] or macOS `~/.gemini/` and `~/Library/Application Support/`):

* **The Brain / Artifact Directory (`~/.gemini/antigravity/brain/` or `~/.gemini/antigravity-ide/brain/`)**
  * Contains folders named after individual conversation UUIDs[3][4].
  * Inside each UUID folder, you will find raw execution logs (`transcript.jsonl`), scratch spaces, subagent trees, and generated files (`task.md`, implementation plans, code diff snapshots)[5][6].
* **The Conversation Databases (`~/.gemini/antigravity/conversations/` or SQLite stores)**
  * Contains `.db` files per conversation that track token metrics, model mappings, and transaction metadata[7].
* **The IDE UI State Database (`%APPDATA%\antigravity\User\globalStorage\state.vscdb` or `antigravity-ide`)**
  * An internal VS Code-style state database that maps what shows up in your sidebar history list (`trajectorySummaries`)[1][8].

---

### 2. How to Export Conversations
Because Antigravity heavily relies on internal database structures and JSONL transcripts rather than a simple user-facing export button[9], you have a few ways to export chats:

* **Method A: Use an IDE Extension (Recommended)**
  * You can install community-maintained utilities inside Antigravity (such as the *Antigravity History* extension from Open VSX)[10]. It adds a dedicated dashboard pane that lets you browse your local brain/db records and **one-click bulk export conversations into Markdown (`.md`) or JSON format**[10].
* **Method B: Manual Extraction via the Brain Directory**
  * If you navigate directly to your `brain/<conversation-id>/` folder, you can grab the `transcript.jsonl` file or any generated text artifacts (like architectural markdown plans)[6][2].
  * *Tip:* You can feed a specific brain path directly back into a fresh session by prompting the agent: 
    > *"Read `~/.gemini/antigravity/brain/<conversation-id>/` and summarize where we left off."*[3][2]

---

### 3. How to Move or Migrate Conversations (e.g., to Antigravity IDE 2.0)
If you are moving machines, updating versions, or your history list has gone blank after an upgrade, a simple file copy is usually required because the IDE state database needs to match the brain files[11].

1. **Close the IDE completely** (make sure no background processes are running)[3].
2. Locate your source data directories:
   * **Brain & Conversation files:** `~/.gemini/antigravity/` (or `antigravity-ide`)[1][3]
   * **UI State storage:** `%APPDATA%\antigravity\User\globalStorage\state.vscdb` (Windows) or `~/Library/Application Support/Antigravity/` (Mac)[1][12]
3. **Perform the Copy / Merge:**
   * Copy the contents of the old `brain/` and `conversations/` folders into your new environment's respective directories[13].
   * If migrating between installations where the UI history list fails to populate, ensure your `state.vscdb` file is also carried over or merged so that the sidebar index recognizes the historical UUIDs[8][13].
