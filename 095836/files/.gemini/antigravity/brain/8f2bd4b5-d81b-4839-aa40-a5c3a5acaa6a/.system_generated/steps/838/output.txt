The search for "window.crypto.subtle file:// protocol origin null secure context chrome firefox safari" returned the following summary:
When you open an HTML file directly from your local file system using the **`file://` protocol** (e.g., double-clicking an `.html` file or typing `file:///path/to/file.html` into your browser address bar), browsers treat the origin as **`null`**[1]. 

Because `file://` / `null` origin is **not** considered a secure context, **`window.crypto.subtle` will be `undefined`** (or throw errors when used) across modern browsers like Chrome, Firefox, and Safari[2][3].

---

### Why does this happen?
The Web Crypto API (`window.crypto.subtle`) provides powerful low-level cryptographic functions[4]. Per the W3C Web Cryptography specification and browser security policies, these features are restricted to **Secure Contexts** to prevent malicious scripts from arbitrarily handling sensitive cryptographic keys or data[2][5]. 
* **Secure contexts** are defined as pages delivered via **HTTPS**, or locally via **`localhost` / `127.0.0.1`**[2][3].
* The **`file://` protocol** lacks a secure origin concept (mapping to an opaque origin of `null`), meaning browsers disable `crypto.subtle` entirely[3][1].

---

### Browser Behavior Matrix (`file://` protocol)

| Browser | Behavior with `file://` (`crypto.subtle`) | Console Error / Symptom |
| :--- | :--- | :--- |
| **Google Chrome / Edge** | `window.crypto.subtle` is **`undefined`**[5][3] | `TypeError: Cannot read properties of undefined (reading 'digest' / 'encrypt' / etc.)`[3] |
| **Mozilla Firefox** | `window.crypto.subtle` is **`undefined`**[3] | `TypeError: window.crypto.subtle is undefined`[3] |
| **Apple Safari** | `window.crypto.subtle` may be undefined or throw security/secure-context exceptions depending on the OS/Safari version. | Restricted due to lack of secure context. |

---

### How to Fix It

To use `window.crypto.subtle`, you must stop running your file through the `file://` protocol and instead serve it through a local development web server using `http://localhost`[6][7]. 

Quick ways to spin up a local server include:

1. **VS Code (Live Server Extension):**
   * Install the *Live Server* extension by Ritwick Dey[6][8].
   * Right-click your HTML file inside VS Code and select **"Open with Live Server"**[6]. It will automatically serve your page at `http://127.0.0.1:[port]`[3].
2. **Node.js (`npx serve`):**
   * Open your project folder in a terminal and run[6]:
     ```bash
     npx serve
     ```
   * Open the provided `http://localhost:[port]` URL in your browser[6].
3. **Python (Built-in Server):**
   * Run the following command in your project directory:
     * **Python 3:** `python3 -m http.server`
     * **Python 2:** `python -m SimpleHTTPServer`
   * Navigate to `http://localhost:8000` in your browser.
