The search for "firestore rest api patch updateMask document create if missing" returned the following summary:
In the Cloud Firestore REST API, the `PATCH` method (`projects.databases.documents.patch`) acts natively as an **upsert**[1]. 

By default, sending a `PATCH` request to a document path will **create the document if it is missing**, or **update it if it already exists**[1].

Depending on whether you want to **merge/update specific fields** or **overwrite the whole document** on creation/update, behavior is managed using the `updateMask` parameter[2]:

---

### Behavior Matrix
1. **With `updateMask` (Upsert + Merge):** 
   If the document *doesn't exist*, it creates it using only the fields specified in the mask. If it *does exist*, it updates only those specific fields and leaves other existing fields untouched[2].
2. **Without `updateMask` (Upsert + Overwrite):** 
   If the document *doesn't exist*, it creates it. If it *does exist*, it completely replaces/overwrites the entire document with the payload provided[2].

---

### Example Request (`curl`)

This example demonstrates how to perform a patched upsert (`create if missing` or `update if present`) targeting specific fields using `updateMask.fieldPaths`[3][1]:

```bash
curl -X PATCH \
"https://firestore.googleapis.com/v1/projects/YOUR_PROJECT_ID/databases/(default)/documents/users/user123?updateMask.fieldPaths=name&updateMask.fieldPaths=status" \
-H "Authorization: Bearer YOUR_ACCESS_TOKEN" \
-H "Content-Type: application/json" \
-d '{
  "fields": {
    "name": { "stringValue": "Alice" },
    "status": { "stringValue": "active" },
    "ignoredField": { "stringValue": "This will not be written because it is missing from the updateMask" }
  }
}'
```

### Key Considerations:
* **No Preconditions Needed:** Do **not** pass `currentDocument.exists=true` in the query string if you want it to create the document when missing. Setting `currentDocument.exists=true` forces a strict requirement that the document must already exist, which will return a `NOT_FOUND` error if it doesn't[3][4].
* **Field Path Syntax:** Each field you want to create/update must be explicitly registered as a query parameter using `updateMask.fieldPaths=fieldName`[5].
