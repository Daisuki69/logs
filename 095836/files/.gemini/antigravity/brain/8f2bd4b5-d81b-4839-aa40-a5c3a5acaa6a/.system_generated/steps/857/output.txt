The search for "firestore rest api documents batchWrite commit delete json format v1" returned the following summary:
In the Google Cloud Firestore REST API (v1), there are two distinct ways to execute multiple write and delete operations:

1. **`documents:batchWrite`**: Applies a batch of writes **non-atomically** and independently. Operations can execute out of order, and you cannot have more than one write per document in a single request[1].
2. **`documents:commit`**: Commits a set of writes **atomically** (either all succeed or all fail together) and in strict order[2].

---

### 1. Endpoint URLs

* **Batch Write (`batchWrite`)**:
  ```http
  POST https://firestore.googleapis.com/v1/projects/{projectId}/databases/{databaseId}/documents:batchWrite
  ```
* **Atomic Commit (`commit`)**:
  ```http
  POST https://firestore.googleapis.com/v1/projects/{projectId}/databases/{databaseId}/documents:commit
  ```
  *(Note: For default databases, `{databaseId}` is usually `(default)`[3]).*

---

### 2. JSON Payload Format (`v1`)

Both endpoints accept a JSON body containing a `writes` array[1][2]. Each element in the array is a `Write` object that can perform operations like `update` (set/upsert), `delete`, or `transform`.

#### Example JSON Payload (Containing a `delete` and an `update`):

```json
{
  "writes": [
    {
      "delete": "projects/my-project-id/databases/(default)/documents/users/user_to_delete"
    },
    {
      "update": {
        "name": "projects/my-project-id/databases/(default)/documents/users/user_to_update",
        "fields": {
          "status": {
            "stringValue": "active"
          },
          "loginCount": {
            "integerValue": "5"
          }
        }
      },
      "updateMask": {
        "fieldPaths": ["status", "loginCount"]
      }
    }
  ]
}
```

---

### 3. Detailed Breakdown of Write Operations inside the JSON

Inside the `writes` array, you can define different actions per object:

* **Delete a Document:**
  Provide the fully qualified resource name of the document to the `delete` field[4].
  ```json
  {
    "delete": "projects/{projectId}/databases/{databaseId}/documents/{collection}/{documentId}"
  }
  ```

* **Create / Update (Set) a Document (`update`):**
  Provide the document path under `name`, wrap your data inside typed `fields`[5], and optionally specify an `updateMask` if you want a partial update (merge behavior)[6].
  ```json
  {
    "update": {
      "name": "projects/{projectId}/databases/{databaseId}/documents/{collection}/{documentId}",
      "fields": {
        "fieldName": { "stringValue": "text value" },
        "numberField": { "integerValue": "10" },
        "boolField": { "booleanValue": true }
      }
    }
  }
  ```

---

### 4. cURL Example (`commit` endpoint)

Here is a full example using `cURL` to perform an atomic commit containing a document update and a document deletion simultaneously:

```bash
curl -X POST \
  "https://firestore.googleapis.com/v1/projects/my-project-id/databases/(default)/documents:commit" \
  -H "Authorization: Bearer YOUR_OAUTH2_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "writes": [
      {
        "update": {
          "name": "projects/my-project-id/databases/(default)/documents/products/item123",
          "fields": {
            "price": { "doubleValue": 49.99 },
            "inStock": { "booleanValue": true }
          }
        }
      },
      {
        "delete": "projects/my-project-id/databases/(default)/documents/temp-cart/cart999"
      }
    ]
  }'
```
