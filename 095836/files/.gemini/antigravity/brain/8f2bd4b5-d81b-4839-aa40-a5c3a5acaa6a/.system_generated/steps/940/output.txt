In `javascript-obfuscator` (v4 and higher)[1], the programmatic Node.js API allows you to fine-tune how string arrays and their function calls are transformed. 

The options **`stringArrayCallsTransform`** and **`stringArrayCallsTransformThreshold`** are crucial for masking the calls made to the string array, making it significantly harder for automated tools or analysts to reverse-engineer strings[2][3].

### Node.js API Usage Example

Below is an example of how to implement `javascript-obfuscator` programmatically using these options:

```javascript
const JavaScriptObfuscator = require('javascript-obfuscator');

const code = `
    const greeting = "Hello World";
    const message = "Obfuscation is working successfully!";
    console.log(greeting, message);
`;

const obfuscationResult = JavaScriptObfuscator.obfuscate(code, {
    // 1. Must be enabled for the string array features to take effect
    stringArray: true,
    
    // 2. Extracts a specific percentage of strings into the array (0 to 1)
    stringArrayThreshold: 1, 

    // 3. Enables transforming/removing direct calls to the string array function 
    // and replacing them with specialized wrapper functions or direct inline decoders.
    stringArrayCallsTransform: true,

    // 4. Determines the proportion (0 to 1) of string array calls that will undergo this transformation
    stringArrayCallsTransformThreshold: 0.75,

    // Additional recommended settings to enhance string protection
    stringArrayEncoding: ['base64'], // Options: ['none'], ['base64'], or ['rc4']
    stringArrayRotate: true,
    stringArrayShuffle: true,
    compact: true
});

console.log(obfuscationResult.getObfuscatedCode());
```

### Detailed Breakdown of Related Options

* **`stringArrayCallsTransform`** (`boolean`, default: `false`): 
  Enables or disables the transformation of calls to the string array. By default, when strings are moved to an array, you see repetitive function calls like `_0x12ab('0x0')`. Enabling this option transforms those calls or routes them through hidden wrapper functions to conceal the lookup patterns.
  
* **`stringArrayCallsTransformThreshold`** (`number`, default: `0.5`, range: `0` to `1`): 
  Controls what percentage of string array calls will be transformed[2]. A value of `1` means *all* string array calls are transformed, whereas `0.5` means roughly half of them are randomized/masked, balancing performance and security.

* **`stringArrayWrappersType`** (`string`, default: `'variable'`): 
  When `stringArrayCallsTransform` is active, you can configure how the wrapper functions are structured (e.g., `'variable'` or `'function'`)[1], making the helper logic blend into your code structure.
