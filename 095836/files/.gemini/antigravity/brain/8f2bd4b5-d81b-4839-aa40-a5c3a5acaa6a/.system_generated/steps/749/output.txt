To delete an entire Cloud Firestore collection using the **Web Namespaced / Compat API (Version 8 syntax)**, you cannot delete the collection directly with a single command[1]. Instead, you must fetch documents in batches and use write batches (`db.batch()`) to delete them iteratively (since Firestore batches are limited to a maximum of 500 writes at a time)[2][3].

Here is a robust helper function using the **v8 compat syntax** (`firebase.firestore()`)[2]:

```javascript
/**
 * Deletes a Firestore collection in batches using the Web v8 compat syntax.
 * 
 * @param {firebase.firestore.Firestore} db - The Firestore compat instance
 * @param {string} collectionPath - The path to the collection (e.g., 'users/123/orders')
 * @param {number} batchSize - Number of documents to delete per batch (max 500)
 */
async function deleteCollection(db, collectionPath, batchSize) {
  const collectionRef = db.collection(collectionPath);
  const query = collectionRef.orderBy('__name__').limit(batchSize);

  return new Promise((resolve, reject) => {
    deleteQueryBatch(db, query, batchSize, resolve, reject);
  });
}

async function deleteQueryBatch(db, query, batchSize, resolve, reject) {
  try {
    const snapshot = await query.get();

    // If there are no documents left, we are done
    if (snapshot.size === 0) {
      resolve();
      return;
    }

    // Otherwise, delete documents in a batch
    const batch = db.batch();
    snapshot.docs.forEach((doc) => {
      batch.delete(doc.ref);
    });

    await batch.commit();

    // Recurse on the next batch to avoid memory issues and handle large collections
    process.nextTick
    setTimeout(() => {
      deleteQueryBatch(db, query, batchSize, resolve, reject);
    }, 0);

  } catch (error) {
    reject(error);
  }
}

// --- How to call it ---
// const db = firebase.firestore();
// deleteCollection(db, 'your-collection-name', 100)
//   .then(() => console.log('Collection deleted successfully'))
//   .catch((error) => console.error('Error deleting collection: ', error));
```

### Key Considerations:
1. **Subcollections:** This script deletes the documents *inside* the specified collection. If those documents contain hidden subcollections, they will not be automatically deleted[4][5] and will need to be cleaned up separately.
2. **Client-side vs. Server-side:** Doing this on the web client exposes your database read/write traffic and is subject to security rules. For large collections, it is strongly recommended to run deletion scripts via a trusted environment (like Node.js with `firebase-admin`)[3] or use the Firebase CLI command (`firebase firestore:delete`)[6].
