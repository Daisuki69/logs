To query a collection using the **Cloud Firestore REST API** with Vanilla JavaScript (`fetch`), you need to use the `runQuery` endpoint via a **`POST`** request[1][2]. 

To accomplish **filtering fields (Mask/Projection)**, **ordering (`orderBy`)**, and targeting a collection, you construct a `structuredQuery` object in the request body[3][4][5].

### Vanilla JavaScript Example

```javascript
async function queryFirestoreDocuments() {
  const projectId = "YOUR_PROJECT_ID";
  const databaseId = "(default)"; // usually (default)
  const collectionName = "users"; // your collection
  
  // Optional: If your Firestore rules require authentication, pass a Bearer token
  const authToken = "YOUR_FIREBASE_AUTH_TOKEN"; 

  // Endpoint for running structured queries
  const url = `https://firestore.googleapis.com/v1/projects/${projectId}/databases/${databaseId}/documents:runQuery`;

  // Construct the Structured Query payload
  const requestBody = {
    structuredQuery: {
      // 1. Specify the collection to query
      from: [{ collectionId: collectionName }],

      // 2. Mask/Projection: Return only specific fields to reduce payload size
      select: {
        fields: [
          { fieldPath: "fullName" },
          { fieldPath: "email" }
        ]
      },

      // 3. Order results by a specific field
      orderBy: [
        {
          field: { fieldPath: "fullName" },
          direction: "ASCENDING" // or "DESCENDING"
        }
      ],

      // Optional: Limit number of results
      limit: 10
    }
  };

  try {
    const response = await fetch(url, {
      method: "POST",
      headers: {
        "Content-Type": "application/json",
        // "Authorization": `Bearer ${authToken}` // Uncomment if auth is needed
      },
      body: JSON.stringify(requestBody)
    });

    if (!response.ok) {
      const errorData = await response.json();
      throw new Error(`Error: ${errorData.error.message}`);
    }

    const data = await response.json();
    
    // Parse and print results
    data.forEach((item, index) => {
      if (item.document) {
        const docPath = item.document.name; // Full resource path
        const fields = item.document.fields;  // Your masked fields
        
        console.log(`Document ${index + 1} (${docPath}):`, {
          fullName: fields.fullName?.stringValue,
          email: fields.email?.stringValue
        });
      }
    });

  } catch (error) {
    console.error("Failed to execute query:", error);
  }
}

// Run the function
queryFirestoreDocuments();
```

### Key Payload Properties Explained:
1. **`from`**: Specifies the target collection layout. `collectionId` takes the name of your Firestore collection[6][5].
2. **`select` (Field Mask)**: Acts as a projection mask[3]. By defining `fields`, you instruct Firestore to only return the specified keys (`fullName`, `email`), omitting everything else[5].
3. **`orderBy`**: Accepts an array of sorting criteria[3]. Each rule requires a `fieldPath` and a `direction` (`ASCENDING` or `DESCENDING`). *Note: Ensure you have matching indexes created in your Firebase Console if sorting combined with inequality filters.*
4. **Response Format**: Firestore returns an array of objects[1]. Each matched document is wrapped inside an object (`item.document`), containing the raw typed values (e.g., `stringValue`, `integerValue`, `booleanValue`).
