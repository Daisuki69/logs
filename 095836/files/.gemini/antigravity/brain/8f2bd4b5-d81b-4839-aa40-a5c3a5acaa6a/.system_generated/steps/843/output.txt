The search for "firestore rest api list documents orderby structuredQuery json" returned the following summary:
To list and order documents using the Cloud Firestore REST API with a JSON payload, you need to use the **`runQuery`** endpoint (`POST :runQuery`) and pass a **`StructuredQuery`** object inside the request body[1][2]. 

*(Note: The standard `listDocuments` GET method only allows basic `orderBy` strings via URL parameters for simple sorting[3], whereas `runQuery` with a `structuredQuery` gives you full querying capabilities like complex filtering and ordering[1][2]).*

### 1. HTTP Request Details
* **Method:** `POST`
* **URL:** 
  ```http
  https://firestore.googleapis.com/v1/projects/{projectId}/databases/{databaseId}/documents:runQuery
  ```
  *(For default databases, `{databaseId}` is usually `(default)`[2]).*
* **Headers:** 
  * `Authorization: Bearer YOUR_ACCESS_TOKEN`
  * `Content-Type: application/json`

---

### 2. JSON Request Body Structure (`structuredQuery` with `orderBy`)

The following JSON example queries a collection named `products`, filters for documents where `price > 10`, and orders the output by the `price` field in **ascending** order (`ASCENDING`), falling back to document name (`__name__`) for stability[4]:

```json
{
  "structuredQuery": {
    "from": [
      {
        "collectionId": "products"
      }
    ],
    "where": {
      "fieldFilter": {
        "field": {
          "fieldPath": "price"
        },
        "op": "GREATER_THAN",
        "value": {
          "integerValue": "10"
        }
      }
    },
    "orderBy": [
      {
        "field": {
          "fieldPath": "price"
        },
        "direction": "ASCENDING"
      },
      {
        "field": {
          "fieldPath": "__name__"
        },
        "direction": "ASCENDING"
      }
    ],
    "limit": 50
  }
}
```

---

### 3. Key Properties for `orderBy` JSON:

* **`orderBy`**: An array of ordering clauses[4]. Firestore executes sorting sequentially based on the order of fields specified in this array.
* **`fieldPath`**: The name of the document field you want to sort by (e.g., `"price"`, `"createdAt"`), or `"__name__"` to sort by the document resource path/ID[4].
* **`direction`**: Can be either:
  * `"ASCENDING"` (A to Z, smallest to largest)
  * `"DESCENDING"` (Z to A, largest to smallest)

> 💡 **Important Rules for Firestore Queries:**
> 1. **Inequality Filters:** If you use an inequality filter (`<`, `<=`, `>`, `>=`, `NOT_EQUAL`), the very first field in your `orderBy` clause **must match** the field used in that inequality filter[4].
> 2. **Composite Indexes:** If your `where` clause and `orderBy` clause reference *different* fields, Firestore will require a composite index[5]. If the index doesn't exist yet, the API will return a `400 Bad Request` error containing a direct URL link in the error message to automatically create the required index in the Firebase Console[5].
