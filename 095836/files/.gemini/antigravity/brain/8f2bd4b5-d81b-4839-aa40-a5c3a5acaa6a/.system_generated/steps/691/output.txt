To display a real-time updating list of **submissions** in an HTML table using **Firebase Firestore (`onSnapshot`)** and **JavaScript (Modular SDK v9/v10+)**, you can use the implementation below[1][2].

```html
<!DOCTYPE html>
<html lang="en">
<head>

    <style>
        table { width: 100%; border-collapse: collapse; font-family: sans-serif; }
        th, td { border: 1px solid #ddd; padding: 8px; text-align: left; }
        th { background-color: #f4f4f4; }
    </style>
</head>
<body>

    <h2>Recent Submissions</h2>
    <table>
        <thead>
            <tr>
                <th>Name</th>
                <th>Email</th>
                <th>Submitted At</th>
            </tr>
        </thead>
        <tbody id="submissions-table-body">
            <!-- Real-time rows will inject here -->
        </tbody>
    </table>

    <!-- Import your JavaScript file as a module -->
    <script type="module" src="app.js"></script>
</body>
</html>
```

### 2. JavaScript Implementation (`app.js`)
Initialize your Firestore database, hook up the `onSnapshot` listener to your `submissions` collection, and map the incoming documents directly into HTML table rows[1][4].

```javascript
// Import the necessary Firestore functions from the Firebase SDK
import { initializeApp } from "firebase/app";
import { getFirestore, collection, query, orderBy, onSnapshot } from "firebase/firestore";

// 1. Your web app's Firebase configuration
const firebaseConfig = {
    apiKey: "YOUR_API_KEY",
    authDomain: "YOUR_AUTH_DOMAIN",
    projectId: "YOUR_PROJECT_ID",
    storageBucket: "YOUR_STORAGE_BUCKET",
    messagingSenderId: "YOUR_MESSAGING_SENDER_ID",
    appId: "YOUR_APP_ID"
};

// 2. Initialize Firebase and Firestore
const app = initializeApp(firebaseConfig);
const db = getFirestore(app);

// 3. Target the table body in the DOM
const tableBody = document.getElementById("submissions-table-body");

// 4. Create a query (Optional: order submissions by date descending)
const submissionsQuery = query(
    collection(db, "submissions"), 
    orderBy("createdAt", "desc")
);

// 5. Set up the real-time listener with onSnapshot
const unsubscribe = onSnapshot(submissionsQuery, (snapshot) => {
    let rowsHTML = "";

    // Iterate through every document in the collection snapshot
    snapshot.forEach((doc) => {
        const sub = doc.data();
        
        // Safely format timestamp if it's a Firestore Timestamp object
        const dateString = sub.createdAt?.toDate 
            ? sub.createdAt.toDate().toLocaleString() 
            : "Just now";

        // Build HTML string for each row
        rowsHTML += `
            <tr>
                <td>${escapeHTML(sub.name || "N/A")}</td>
                <td>${escapeHTML(sub.email || "N/A")}</td>
                <td>${dateString}</td>
            </tr>
        `;
    });

    // Render the rows into the table body all at once
    tableBody.innerHTML = rowsHTML;

}, (error) => {
    console.error("Error fetching real-time submissions: ", error);
});

// Helper function to prevent Cross-Site Scripting (XSS)
function escapeHTML(str) {
    return str.replace(/[&<>'"]/g, 
        tag => ({ '&': '&amp;', '<': '&lt;', '>': '&gt;', "'": '&#39;', '"': '&quot;' }[tag] || tag)
    );
}

// Optional: Call unsubscribe() if you ever need to destroy/detach the listener 
// e.g., if the user navigates away from a Single Page Application (SPA) view.
```

### Key Takeaways:
1. **`onSnapshot()`**: Fires immediately with the current state of the database and triggers again automatically whenever a document is added, updated, or deleted[1][4].
2. **`tableBody.innerHTML = rowsHTML`**: Re-rendering the inner HTML template string on every snapshot update is clean for small-to-medium lists. For massive datasets, you may want to look into diff-checking individual snapshot changes (`snapshot.docChanges()`)[1].
3. **Security (`escapeHTML`)**: Always sanitize user-generated inputs (like names or form text) before injecting them directly into `innerHTML` to prevent XSS attacks.
